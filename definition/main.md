# Traning progress tracker Kaizen

## ACCs
* create a training plan
    * include a standard exercise library and allow user-created exercises
    * add exercises
        * symbolic pictures for the standard exercises and machines
    * add up to 2 number values for the machine settings
    * add weight
    * add sets
    * add reps per set

* Platform
    * mobile-first installable web app (PWA)
    * runs in iPhone Safari and can be added to the Home Screen; no App Store
    * live static hosting with automatic deployment from GitHub

* start a trainig session
    * use a plan
    * store the date
    * track the time
    * default:
        * values achieved in last training
        * show last-session values for each set alongside today's editable values
    * set reps per exercise
    * override weight
    * optional, manually started countdown break button; it is never required
    * progression suggestions are a later feature

* trend view
    * show trend comparison of sessions over time
        * time
        * total reps across all sets
        * sets
        * weight
        * etc
        * one line per exercise in the total-reps chart
        * a separate weight-progress chart with one line per exercise
    
* data persisted on the phone
* if a workout is interrupted, resume it in the same state as if the interruption had not happened

* design
    * futuristic
    * cyberpunk
    * minimalistic
